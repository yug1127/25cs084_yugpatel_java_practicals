## 💻 Practical Code Repository Overview (Practicals 1 to 14)

This repository contains complete, self-contained Java source files for Practicals 1 through 14 of the Object-Oriented Programming (CEUE203) course, covering core to advanced Java concepts and building towards the MiniBank console project.

| Practical | File Name | Topics Covered |
| :--- | :--- | :--- |
| **01** | `Practical01.java` | Enums & Switch Expressions (Vending Machine), Records (Toll Booth), Console Menu Shell (`MiniBank`) |
| **02** | `Practical02.java` | Smart Thermostat, Cinema Booking state management, Encapsulated `Customer` & `Account` (`AC0001`, `CUST101`) |
| **03** | `Practical03.java` | Object methods (`toString`, `equals`, `hashCode` contract), nested `Address` static class & deep cloning |
| **04** | `Practical04.java` | Regex validations (Mobile, Email, Password), Chat Filter, Command Parser records, `StringBuilder` Statement Formatter |
| **05** | `Practical05.java` | Abstract `Account` base class, Run-time Polymorphism with `SavingsAccount`, `CurrentAccount`, and `FixedDepositAccount` |
| **06** | `Practical06.java` | Interfaces (`Transactable`, `InterestBearing`), `@FunctionalInterface WithdrawRule` with Lambdas, `Premium` marker interface |
| **07** | `Practical07.java` | Custom Annotations (`@Id`, `@Positive`) and Reflection Validation (`AnnotationValidator`) |
| **08** | `Practical08.java` | Checked Exception Hierarchy (`BankException`, `InsufficientFundsException` with shortfall, `InvalidAmountException`) |
| **09** | `Practical09.java` | Multithreading, Runnable workers (`AccountWorker`), Race condition simulation vs. Thread synchronization |
| **10** | `Practical10.java` | `ExecutorService` Thread Pools (`TransactionProcessor`), Producer-Consumer (`wait`/`notify`), Deadlock Prevention via consistent lock ordering |
| **11** | `Practical11.java` | Object Serialization (`ObjectOutputStream`/`ObjectInputStream`), NIO `Path` & `Files` End-of-Day report generator |
| **12** | `Practical12.java` | Java Collections Framework (`HashMap` store, `ArrayList` history, `Comparator` balance sorting) |
| **13** | `Practical13.java` | Generic `Repository<T>`, Dynamic reflection for `@Id` entity keys, `@SafeVarargs` batch operations |
| **14** | `Practical14.java` | Capstone Layered MiniBank Architecture (`UI` -> `BankService` -> `Repository`), simulated JUnit `@Test` suite assertions |

## How to Compile & Run

Prerequisites: JDK 17 or higher.

```bash
# Compile any practical
javac Practical01.java

# Run the practical demonstration
java Practical01
```

Each practical file contains its own `public static void main(String[] args)` runner that automatically demonstrates all parts and prints expected output matching the practical manual specifications.
